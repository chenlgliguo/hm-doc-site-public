# 管理人员评价指标体系

> 421项主指标 + 115项高危反向指标
> 用于选人、用人、防风险、做管理者画像的完整指标池

## 页面信息

- 版本：Pro V3.2
- 文档类型：完整指标池
- 适用场景：选人、用人、防风险、管理者画像
- 原始文件：`management_evaluation_indicators_pro_v3_2.docx`

## 核心判断

能力决定一个人能做多大的事，心性决定他会把能力用来成事还是害人。

指标池不是全量评分表，真正使用时必须按层级、岗位和业务阶段抽取。

管理人员的核心评价，是他拿到人、钱、权、资源以后，让公司变强还是变危险。

## 使用原则

底层原则：这不是让每个管理者都评421项。这是一个“指标池”。真正使用时，要按岗位、层级、业务阶段抽取。选错指标，比没有指标更危险。

<a id="part-1-main-indicators"></a>

## 第一部分：421项主指标

<a id="class-a"></a>

### A类：心性、良知与德性底盘

这一类是底线。心性不行，能力越强，风险越大。

- 1. 心术端正：做事出发点正不正，是为了成事，还是为了算计、谋私、害人。
- 2. 正直：能不能分清是非，不颠倒黑白，不为了利益冤枉别人。
- 3. 诚实：汇报、承诺、解释、数据是否真实，不撒谎、不隐瞒、不编故事。
- 4. 守信：答应的事能不能做到，做不到是否提前说明。
- 5. 良心底线：没人监督时，会不会故意坑公司、坑客户、坑员工、坑合作方。
- 6. 善良：有能力伤害别人时是否克制，有权力压人时是否不欺负人。
- 7. 厚道：做事是否留余地、讲分寸，不吃相难看，不占尽便宜。
- 8. 感恩心：是否记得公司、老板、团队、他人给过的机会、资源和帮助。
- 9. 知恩图报：不只是嘴上感恩，而是关键时候有实际回馈和担当。
- 10. 公道心：处理人和事时，心里有没有一杆秤，不偏袒亲信，不打压异己。
- 11. 是非观：能不能判断什么是对、什么是错，而不是只看输赢和利益。
- 12. 敬畏心：是否敬畏法律、规则、组织、客户、员工、风险和后果。
- 13. 羞耻心：做错事、失信、甩锅、伤害别人后，会不会感到难堪并愿意改。
- 14. 同理心：能不能理解别人的处境、压力和感受，而不是只顾自己方便。
- 15. 不欺弱小：看他对基层员工、司机、保洁、实习生、小供应商是什么态度。
- 16. 不占便宜：不贪小便宜，不拿不该拿的，不把公司资源当私人物品。
- 17. 不害人：竞争可以，争利益可以，但不造谣、不设局、不栽赃、不背后下黑手。
- 18. 利他意识：是否愿意在合理范围内帮助团队、成就他人、共享经验。
- 19. 成全他人：能不能让优秀下属冒出来，而不是害怕别人超过自己。
- 20. 容人量：能不能容得下不同意见、不同性格、比自己强的人。
- 21. 恩怨处理能力：有矛盾时能否就事论事，不长期记仇、不公报私仇。
- 22. 义利观：利益和道义冲突时，会不会守住底线，不赚昧良心的钱。
- 23. 真诚度：待人接物是否真实稳定，不长期戴面具、不当面一套背后一套。
- 24. 忠厚可靠：合作越久，别人越放心，还是越接触越需要防备。
- 25. 善待平台与机会：是否把岗位、权力、资源当责任，而不是当提款机、私器、个人山头。

<a id="class-b"></a>

### B类：学习与认知底盘

这一类判断的是：这个人能不能学进去、想清楚、用出来。

- 26. 学习能力：能不能持续吸收新知识、新规则、新方法。
- 27. 理解能力：能不能听懂别人真正表达的意思。
- 28. 记忆能力：能不能记住关键任务、承诺、人员情况、历史问题。
- 29. 应用能力：学到的东西能不能真正用到工作里。
- 30. 学习转化能力：能不能把知识转化成方法、流程、动作和结果。
- 31. 复盘学习能力：做完事以后，能不能从成功和失败中总结经验。
- 32. 逻辑思维能力：说话、判断、做事是否有因果、有层次、有顺序。
- 33. 跨界知识储备：是否懂业务、财务、法律、销售、供应链、人性、组织管理等知识。
- 34. 跨界整合能力：能不能把不同领域的知识组合起来解决现实问题。
- 35. 思想清明度：脑子是否清楚，判断是否干净，逻辑是否顺畅，不糊涂、不混乱。

<a id="class-c"></a>

### C类：本质洞察、人性识别与商业直觉

这一类是高层和顶级管理者的上限能力。

- 36. 悟性：别人讲一遍，能不能迅速明白背后的逻辑、本质、规则和未说出口的意思。
- 37. 洞察力：能不能从细节、异常、人的反应、局势变化中看出真正的问题。
- 38. 本质洞察力：能不能从复杂表象中迅速抓住事情的根本。
- 39. 第一性原理思考能力：能不能回到最底层的问题，比如这事到底靠什么成立、靠什么赚钱、卡在哪里。
- 40. 关键变量识别能力：能不能找出真正决定结果的变量。
- 41. 模式识别能力：能不能从不同事情中看出重复规律。
- 42. 人性洞察力：能不能看懂人的欲望、恐惧、利益、面子、嫉妒、贪婪、忠诚、怨气。
- 43. 动机识别能力：能不能识别别人行为背后的真实动机。
- 44. 算计识别能力：能不能看出布局、套路、话术、试探、甩锅和利益设计。
- 45. 真假识别能力：能不能判断数据、资源、承诺、关系、成绩是真是假。
- 46. 伪装识别能力：能不能看出别人是否在装忠诚、装感恩、装努力、装专业、装资源。
- 47. 信息验证能力：不只靠感觉，还能多渠道核实、看行为、看结果、看长期。
- 48. 商业直觉：能不能快速判断一个项目、客户、市场、资源、合作模式是否有价值。
- 49. 未知判断能力：面对没见过的新情况，能不能快速建立判断框架。
- 50. 不确定性决策能力：信息不完整、时间有限、风险存在时，能不能做出相对正确决策。
- 51. 危险感知能力：能不能提前闻到项目、客户、人员、资金、舆情、团队要出事的味道。
- 52. 局势预判能力：能不能判断事情下一步会怎么发展。
- 53. 机会窗口判断能力：能不能判断机会什么时候该抓、什么时候该放。
- 54. 快速试错验证能力：面对未知机会，能不能小成本验证，而不是直接豪赌。

<a id="class-d"></a>

### D类：创造、颠覆、规则建构与系统升级

普通管理者执行系统，优秀管理者优化系统，顶级管理者创造系统。

- 55. 创造能力：没有现成答案时，能不能创造新工具、新流程、新模式、新方法。
- 56. 从0到1能力：能不能从无到有，把想法做成最小可用版本。
- 57. 问题重新定义能力：能不能把表面问题重新定义成真正问题。
- 58. 工具创造能力：能不能创造表格、模板、清单、模型、SOP、评分表、流程工具。
- 59. 方法论创造能力：能不能把零散经验提炼成可复制的方法。
- 60. 模式创造能力：能不能创造新的业务模式、管理模式、合作模式、增长模式。
- 61. 商业模式创新能力：能不能重新设计赚钱方式、收费方式、交付方式、客户关系和资源组合。
- 62. 组织模式创新能力：能不能创造更适合业务发展的组织结构。
- 63. 思想框架创造能力：能不能创造一套解释问题、指导行动、统一认知的思想框架。
- 64. 规则创建能力：能不能在混乱、模糊、无序的环境里建立规则。
- 65. 规则规划能力：能不能判断哪些规则先立、哪些后立、哪些要严、哪些要弹性。
- 66. 制度设计能力：能不能把规则变成制度，让组织长期运行。
- 67. 标准制定能力：能不能定义什么叫好、差、合格、不合格。
- 68. 旧系统诊断能力：颠覆之前，能不能看懂旧系统为什么存在、哪里卡住、哪些不能乱动。
- 69. 建设性颠覆能力：能不能打破陈旧低效系统，并建立更好的替代系统。
- 70. 升级换代能力：能不能推动组织从人治到制度、从经验到数据、从混乱到流程。
- 71. 系统重构能力：能不能重构组织、业务、流程、利益分配、客户结构、决策机制。
- 72. 抽象提炼能力：能不能从个案中提炼通用规律。
- 73. 概念命名能力：能不能给复杂问题命名，让团队能识别、讨论、管理它。
- 74. 试验设计能力：能不能小范围试点、设置指标、控制成本、判断成败。
- 75. 迭代能力：能不能根据反馈不断优化新工具、新模式、新规则。
- 76. 规模化复制能力：能不能让新方法从个人能力变成组织能力。
- 77. 新秩序建立能力：能不能建立新的权责、协同、评价、利益、文化和工作习惯。
- 78. 未来想象力：能不能想象未来客户、行业、组织、工具、商业模式会怎么变。
- 79. 创造落地能力：能不能把想法变成方案，方案变成试点，试点变成制度，制度变成结果。

<a id="class-e"></a>

### E类：目标、执行与成事能力

这是基层和中层管理者的基本盘。

- 80. 目标理解力：能不能理解老板和公司的真实目标，而不是只听表面任务。
- 81. 抓重点能力：能不能在复杂事务中抓住最关键的问题。
- 82. 任务拆解能力：能不能把大目标拆成具体任务、步骤、负责人、时间节点。
- 83. 计划制定能力：能不能制定清晰、可执行、可检查的计划。
- 84. 推进能力：事情交给他以后，能不能持续往前推。
- 85. 结果交付能力：最后能不能把结果交出来，而不是只讲过程努力。
- 86. 执行闭环能力：安排、跟进、检查、反馈、复盘是否完整。
- 87. 解决问题能力：遇到问题是找方法，还是找理由、找借口、找人背锅。
- 88. 过程管控能力：事情进行中能不能盯住关键节点，防止跑偏。
- 89. 纠偏能力：发现错误后能不能及时调整，而不是硬着头皮继续错。
- 90. 质量控制能力：能不能保证产品、服务、项目、交付的稳定质量。
- 91. 效率优化能力：能不能减少浪费、拖延、无效沟通和低效流程。

<a id="class-f"></a>

### F类：责任、担当与可信任度

管理者不是只要会做事，更要能担事、扛事、守事。

- 92. 责任心：出了问题先想怎么解决，而不是先想怎么撇清自己。
- 93. 担当能力：关键时刻敢不敢站出来，敢不敢扛责任、扛压力、扛结果。
- 94. 结果负责度：是否真正对最终结果负责，而不是只对“我已经安排了”负责。
- 95. 不甩锅程度：是不是动不动把问题推给下属、老板、客户、环境、其他部门。
- 96. 忠诚度：是否真正站在公司利益上做事，而不是只拿公司平台养自己。
- 97. 可信任度：老板交给他的事、人、钱、资源、信息，能不能放心。
- 98. 光明磊落程度：做事是否坦荡，还是背后搞动作、传话、挑拨、下套。
- 99. 公私边界：能不能分清公司资源、个人利益、人情关系、岗位权力。
- 100. 信息透明度：是否如实汇报，不藏问题、不制造信息差、不报喜不报忧。
- 101. 承诺兑现度：答应的事是否能兑现，做不到是否提前说明。
- 102. 关键时刻可靠度：平时说得好没用，关键时候能不能站得住、扛得住、顶得上。
- 103. 组织安全意识：是否知道自己的行为会影响团队秩序、公司安全和组织信任。

<a id="class-g"></a>

### G类：判断、决策与经营战略能力

这一类适合中高层、高层、经营负责人。

- 104. 判断力：能不能判断真假、轻重、缓急、利弊。
- 105. 决策果断度：该拍板时能不能拍板，不拖、不耗、不反复摇摆。
- 106. 风险意识：做事前能不能看到漏洞、后果和代价。
- 107. 成本意识：知道时间、人力、金钱、机会成本都不是无限的。
- 108. 全局观：能不能站在公司整体利益看问题。
- 109. 长期思维：会不会为了短期好看，牺牲长期价值。
- 110. 事实判断能力：能不能基于事实判断，而不是被情绪、关系、面子带偏。
- 111. 取舍能力：能不能判断什么该做，什么不该做。
- 112. 经营者意识：是否像老板一样看收入、成本、利润、现金流、风险和团队。
- 113. 商业模式理解能力：是否理解公司靠什么赚钱、利润在哪里、风险在哪里。
- 114. 行业趋势判断能力：能不能判断行业机会、周期、变化和风险。
- 115. 政策敏感度：能不能感知政策、监管、规则变化对业务的影响。
- 116. 战略高度：能不能站在更高层面看公司方向和长期竞争。
- 117. 战略拆解能力：能不能把战略变成年度目标、季度计划、团队动作和具体结果。

<a id="class-h"></a>

### H类：危机、突发事件与变化应对能力

管理者不能只会处理正常情况。

- 118. 突发事件处理能力：事情突然发生时，能不能快速稳住局面、减少损失。
- 119. 危机处理能力：事情升级成危机时，能不能保护公司、稳定团队、控制风险。
- 120. 应变能力：环境、人、客户、政策、条件变化时，能不能及时调整打法。
- 121. 承压能力：压力一大，是稳住团队，还是自己先乱。
- 122. 抗挫能力：失败后能不能复盘、调整、重新打。
- 123. 临场稳定性：现场出问题时，是否能冷静判断、不慌、不乱。
- 124. 重大风险处置能力：面对重大损失、重大投诉、重大纠纷时，能不能组织资源处理。
- 125. 舆情初判能力：能不能判断一件小事是否可能发酵成大事。

<a id="class-i"></a>

### I类：带人、用人与组织建设能力

管理者不是自己能干就够了，关键是能不能让一群人变强。

- 126. 识人能力：能不能看出谁靠谱、谁能干、谁偷懒、谁有风险。
- 127. 用人能力：能不能把合适的人放在合适的位置上。
- 128. 培养下属能力：能不能让手下人成长，而不是永远靠自己硬扛。
- 129. 分工能力：能不能分清谁负责什么，避免职责混乱。
- 130. 授权能力：该放手时能不能放手，不是什么都抓在自己手里。
- 131. 管控能力：授权以后能不能检查结果，不让事情失控。
- 132. 激励能力：能不能让团队有动力、有方向、有奔头。
- 133. 团队稳定能力：他管的团队，是越带越稳，还是越带越散。
- 134. 冲突处理能力：团队有矛盾时，能不能处理，而不是激化。
- 135. 公平奖惩能力：好的人能不能被看见，差的行为能不能被处理。
- 136. 梯队建设能力：能不能培养下一层干部。
- 137. 接班人培养能力：他离开、升职、生病、出差时，有没有人能接住。
- 138. 干部识别能力：能不能从团队里发现未来的主管、经理、负责人。
- 139. 淘汰能力：能不能处理长期低效、破坏团队、价值观不合的人。
- 140. 组织韧性建设能力：团队遇到压力、变化、打击时，能不能继续运转。

<a id="class-j"></a>

### J类：沟通协调、人情世故与谈判博弈

管理不是只讲道理，也要懂人、懂场合、懂利益。

- 141. 向上沟通能力：能不能及时、真实、清楚地向老板反馈情况。
- 142. 向下传达能力：能不能把公司的要求讲明白，让下面知道怎么做。
- 143. 横向协调能力：能不能和其他部门配合，而不是制造对立。
- 144. 沟通清晰度：说话是否清楚、准确、有重点。
- 145. 人情世故能力：懂不懂分寸、礼数、面子、台阶、利益和关系维护。
- 146. 场合分寸感：知道什么场合说什么话，什么话不能说。
- 147. 说服能力：能不能让别人理解、相信并愿意配合。
- 148. 谈判能力：能不能争取条件、守住底线、促成合作。
- 149. 博弈意识：能不能看清对方的筹码、动机、底线和真实目的。
- 150. 利益分配能力：能不能设计让多方愿意参与的利益结构。
- 151. 复杂关系平衡能力：多方利益冲突时，能不能稳住局面，不让事情失控。

<a id="class-k"></a>

### K类：外部资源、社会资源与政商业资源

资源型管理者一定要看两面：资源能不能用，资源会不会反噬公司。

- 152. 人脉资源：有没有真正愿意帮他、支持他、配合他的人。
- 153. 社会关系资源：是否能连接行业、政府、协会、商会、供应链、客户圈、渠道圈等资源。
- 154. 金融资源：是否具备接触银行、资金方、投资人、信用资源、融资渠道的能力。
- 155. 执法、监管、法务协同资源：是否知道在合法合规范围内，通过公安、法院、律师、税务、市场监管、劳动监察等路径保护公司。
- 156. 多国政商业资源：是否具备跨国家、跨地区、跨制度的政务、商业、资本、渠道和合规资源连接能力。
- 157. 资源真实性：他说的资源是真的，还是吹出来的。
- 158. 资源调动能力：有资源之后，能不能真正调动起来解决问题。
- 159. 资源转化成果能力：资源最后能不能变成订单、合作、资金、渠道、解决方案或风险化解。
- 160. 资源使用边界：会不会合法、合规、低风险地使用资源。
- 161. 联盟搭建能力：能不能把客户、渠道、供应商、资本方、地方资源组成合作网络。

<a id="class-l"></a>

### L类：客户、市场、销售与商务增长能力

适合销售型、市场型、增长型、总经理型管理者。

- 162. 客户洞察能力：能不能理解客户需求、痛点、预算、顾虑和决策链。
- 163. 大客户经营能力：能不能长期维护关键客户，而不是只会一次性成交。
- 164. 客户资源质量：客户是否有真实需求、真实购买力和真实合作可能。
- 165. 渠道建设能力：能不能建立稳定、可复制、可管理的渠道资源。
- 166. 市场开拓能力：进入新区域、新行业、新客户群时，能不能打开局面。
- 167. 销售转化能力：能不能把线索变成订单，把意向变成合同，把合同变成回款。
- 168. 回款意识：是否重视回款、账期和现金落袋。
- 169. 客户信用判断能力：能不能判断客户是否可靠，是否有拖款、赖账、纠纷风险。
- 170. 价格谈判能力：能不能守住价格、利润和合作条件。
- 171. 客户投诉处理能力：客户出问题时，能不能稳住客户、查明原因、减少损失、修复关系。

<a id="class-m"></a>

### M类：财务经营与资金安全能力

很多管理人员能管事，但不会管钱，这不是真管理。

- 172. 利润与P&L意识：是否能对收入、成本、利润、经营结果负责。
- 173. 毛利意识：能不能保护毛利，不为了表面业绩牺牲利润质量。
- 174. 现金流意识：是否知道公司真正危险，往往不是没利润，而是没现金流。
- 175. 预算管理能力：能不能制定预算、控制预算、解释预算偏差。
- 176. 成本结构理解能力：是否知道哪些是固定成本，哪些是变动成本，哪些成本可以优化。
- 177. 投入产出意识：花钱、用人、投资源之前，是否判断产出是否值得。
- 178. 财报基础理解能力：至少能看懂收入、成本、利润、现金流、应收账款、负债等核心数据。
- 179. 资金安全意识：涉及付款、收款、账户、审批、借款、担保时，有没有底线和流程意识。

<a id="class-n"></a>

### N类：法务、合规、廉洁与安全能力

能力强但没合规意识的人，会给公司埋雷。

- 180. 合同意识：签合同前是否关注主体、金额、期限、违约责任、付款条件、交付标准。
- 181. 证据链意识：遇到纠纷时，是否知道保留合同、聊天记录、发票、验收单、付款记录等证据。
- 182. 用工合规意识：管理员工时是否懂基本劳动风险。
- 183. 税务边界意识：知道业务操作不能乱做账、乱开票、乱避税。
- 184. 合规红线意识：知道哪些事短期有利也不能碰。
- 185. 反舞弊意识：能不能识别虚假报销、吃回扣、假合同、假供应商、利益输送。
- 186. 供应商廉洁风险意识：能不能防止采购、外包、工程、渠道环节出现暗箱操作。
- 187. 数据与信息安全意识：客户数据、员工数据、财务数据、商业机密是否能守住。
- 188. 知识产权意识：是否知道商标、专利、版权、软件、设计、商业方案不能乱用或泄露。
- 189. 安全生产意识：涉及工厂、仓库、施工、物流、门店、现场管理时，是否重视人身和财产安全。

<a id="class-o"></a>

### O类：流程、系统、数据与AI能力

新时代管理者不能只靠嘴和经验。

- 190. 流程制度化能力：能不能把经验变成流程，把流程变成标准。
- 191. SOP建设能力：能不能建立标准作业流程，让新人也能按规则执行。
- 192. 项目管理能力：能不能管目标、进度、人员、预算、风险和交付。
- 193. 文档化能力：重要事项能不能沉淀成文件、表格、流程、模板。
- 194. 知识沉淀能力：项目做完后，经验能不能留下来，避免团队反复踩坑。
- 195. 数据敏感度：看到数据变化，能不能发现异常、机会和风险。
- 196. 数据分析能力：能不能用数据支持判断，而不是全靠感觉和经验。
- 197. AI与数字化应用能力：能不能利用AI、软件、系统、表格、协同工具提升效率和管理质量。

<a id="class-p"></a>

### P类：身体、精神与状态承载能力

管理者是高压岗位，状态不行，能力也发挥不出来。

- 198. 身体状态：身体是否能承受管理压力、工作节奏、出差、加班和连续处理问题。
- 199. 精神状态：精神是否饱满、稳定、有力量，不长期低能量、颓废、逃避。
- 200. 情绪稳定度：遇到问题是否稳定，不轻易爆炸、发疯、失控。
- 201. 怒火控制能力：是否动不动用发火压人。
- 202. 怨气控制能力：是否长期觉得自己委屈、公司亏待他、别人对不起他。
- 203. 自我反省能力：出了问题能不能看见自己的责任。
- 204. 听劝程度：别人指出问题时，是能吸收，还是立刻防御、反击、找理由。
- 205. 长期稳定性：这个人是否能长期靠谱，而不是一阵好、一阵坏。

<a id="class-q"></a>

### Q类：管理者个人形象与为人师表

管理者本身就是团队的样板。

- 206. 职业形象：是否干净、得体、稳重，符合岗位、场合和公司气质。
- 207. 精神面貌：对外呈现是否有管理者该有的精神状态和能量。
- 208. 仪态气场：站姿、坐姿、眼神、动作、表达节奏是否稳、正、有分寸。
- 209. 语言形象：说话是否清楚、克制、专业，不低俗、不乱骂、不阴阳怪气。
- 210. 场合感：是否知道公开场合、私下场合、客户场合、政府场合、内部会议该怎么表现。
- 211. 对外代表性：能不能代表公司出面，不乱承诺、不丢公司脸。
- 212. 个人口碑：员工、客户、合作方、同行对他的长期真实评价如何。
- 213. 言行一致度：嘴上讲的，自己是否真的做到。
- 214. 稳重程度：是否成熟、稳当、压得住场，不轻浮、不冒进、不乱表态。
- 215. 体面感：有权、有利、有冲突、有压力时，是否还能保持基本尊严和风度。
- 216. 榜样作用：下属是否能从他身上学到负责、守信、专业、担当和规矩。
- 217. 以身作则：要求别人做到的，自己是否先做到。
- 218. 纪律示范：是否带头遵守公司纪律、流程、制度，不搞特殊。
- 219. 价值观示范：日常行为是否传递责任、诚信、公平、结果、长期主义。
- 220. 公私分明：能不能分清公司利益、个人利益、人情关系。
- 221. 尊重下属：批评事，不羞辱人；要结果，不搞人格攻击。
- 222. 公平正派：处理人和事是否公道，不偏袒亲信，不打压异己。
- 223. 谦逊与学习姿态：有成绩、有权力、有资源后，是否还能听意见、能自省、能学习。
- 224. 生活作风边界：私人生活是否会外溢成公司风险、声誉风险或团队管理风险。
- 225. 教化与带风气能力：能不能把团队风气带正，让团队更负责、更守信、更讲规则、更少内耗。

<a id="class-r"></a>

### R类：国际化与海外业务专项能力

- 226. 外语沟通能力：能不能进行真实商务沟通、邮件、会议、谈判。
- 227. 跨文化沟通能力：能不能理解不同国家的表达方式、时间观念、契约观念、礼仪和禁忌。
- 228. 国际商务礼仪：是否懂不同国家商务场景中的称呼、宴请、会议、谈判习惯。
- 229. 海外公司治理意识：是否理解海外公司注册、董事、股权、税务、银行账户、审计等规则。
- 230. 跨境支付与汇率意识：是否知道跨境收付款、外汇波动、手续费、合规路径的风险。
- 231. 国际物流与关务意识：是否懂报关、清关、物流、仓储、保险、贸易条款。
- 232. 海外用工意识：是否知道海外招聘、签证、劳动合同、薪酬、解雇、社保福利不能照搬国内规则。
- 233. 地缘风险意识：能不能判断战争、制裁、政局、汇率、监管、民族宗教冲突对业务的影响。
- 234. 本地化用人能力：海外业务能不能用当地人、管当地团队，而不是只靠自己人空降。
- 235. 海外合规顾问网络：是否有律师、会计师、税务顾问、移民顾问、行业顾问等专业资源。

<a id="class-s"></a>

### S类：品牌、声誉与公关能力

- 236. 品牌意识：知道自己的行为会影响公司形象。
- 237. 对外表达能力：面对客户、媒体、合作方、政府、公众时，能不能说清楚、说稳、说有边界。
- 238. 舆情判断能力：能不能判断一件小事是否可能发酵成大事。
- 239. 危机公关能力：负面事件发生后，能不能控制信息、回应问题、修复信任。
- 240. 媒体资源：是否有合法、正常、可验证的媒体沟通资源。
- 241. 公众形象管理：个人言行是否会给公司带来负面影响。
- 242. 发言边界意识：知道什么能说、什么不能说，什么时候沉默比解释更好。
- 243. 声誉风险意识：知道一次失信、丑闻、恶性投诉，可能毁掉长期积累。

<a id="class-t"></a>

### T类：技术、产品与研发管理专项能力

- 244. 技术判断力：能不能判断技术方案是否可靠、可扩展、可维护。
- 245. 技术路线规划能力：能不能根据业务阶段选择合适技术路线，而不是盲目追新。
- 246. 架构与系统设计能力：能不能设计稳定、清晰、可扩展的系统结构。
- 247. 技术债管理能力：能不能识别、控制、清理长期积累的技术隐患。
- 248. 研发质量控制能力：能不能保证代码、测试、上线、交付质量。
- 249. 产品技术结合能力：能不能理解业务和用户，而不是只站在技术角度做东西。
- 250. 技术人才识别能力：能不能看出谁是真高手，谁只是会讲术语。
- 251. 技术风险预判能力：能不能提前发现安全、性能、稳定性、交付延迟风险。
- 252. 技术安全与合规意识：是否重视数据安全、权限、隐私、系统安全、知识产权。
- 253. 技术创新落地能力：能不能把新技术真正变成效率、产品、收入或成本优势。

<a id="class-u"></a>

### U类：行政、后勤与内部保障专项能力

- 254. 服务意识：能不能服务业务、服务团队，而不是制造官僚感。
- 255. 秩序维护能力：能不能让办公室、会议、制度、接待、后勤保持有序。
- 256. 资产管理能力：公司物品、车辆、设备、办公资产是否有账、有管控、不浪费。
- 257. 后勤保障能力：关键时刻能不能保障办公、接待、差旅、场地、物资、车辆。
- 258. 会议与接待能力：能不能把会议、客户接待、政府接待、重要活动安排得体。
- 259. 印章证照档案管理能力：印章、证照、合同、档案是否安全、规范、可追溯。
- 260. 费用节制能力：行政费用是否合理，不铺张、不浪费、不乱花。
- 261. 内部服务满意度：员工和业务部门是否认为他的工作真正提高了效率，而不是增加麻烦。

<a id="class-v"></a>

### V类：生产、运营、供应链与交付专项能力

- 262. 供应链管理能力：能不能保障供应稳定、成本合理、风险可控。
- 263. 采购管理能力：能不能控制价格、质量、交期和供应商廉洁风险。
- 264. 库存周转能力：能不能减少积压、缺货、呆滞库存。
- 265. 交付准时能力：能不能按时、按质、按量交付。
- 266. 现场管理能力：现场是否有秩序、安全、效率和质量。
- 267. 设备资产管理能力：设备是否维护到位，故障、闲置、损耗是否可控。
- 268. 安全与品质控制能力：能不能守住安全生产和产品、服务质量底线。
- 269. 产能规划能力：能不能判断产能、人力、设备、订单之间的匹配关系。
- 270. 供应商开发能力：能不能找到可靠、可替代、可长期合作的供应商。
- 271. 成本、交期、质量平衡能力：能不能在成本、速度、质量之间做正确取舍。

<a id="class-w"></a>

### W类：法律、诉讼、合规与风控专项能力

- 272. 法律风险识别能力：能不能在合同、用工、交易、税务、数据、知识产权、合作模式里提前看出法律风险。
- 273. 合同结构设计能力：能不能设计合同主体、付款、交付、验收、违约、解除、争议解决等结构。
- 274. 合同审查能力：能不能看出合同里的坑，比如责任不清、付款条件不利、授权不明、主体错误。
- 275. 证据链设计能力：事情还没出纠纷前，就知道哪些证据要留、谁留、怎么留、什么时候留。
- 276. 纠纷预防能力：能不能通过合同、流程、沟通记录、验收机制，把纠纷提前压住。
- 277. 诉讼策略能力：真打官司时，能不能判断打不打、怎么打、打到什么程度、成本和收益是否值得。
- 278. 非诉谈判能力：能不能在不进入诉讼的情况下，通过谈判、调解、律师函、证据压力解决问题。
- 279. 监管应对能力：面对市场监管、税务、劳动监察、消防、数据监管等检查或投诉时，能不能合法、专业、稳住局面。
- 280. 劳动用工法律意识：处理招聘、试用、调岗、辞退、加班、社保、竞业、保密时，是否知道基本红线。
- 281. 公司治理法律意识：是否懂股权、董事、章程、授权、印章、审批、关联交易、重大事项决策的基本规则。
- 282. 投融资法律意识：涉及融资、借款、担保、股权、投资协议、对赌、回购时，能不能看出核心风险。
- 283. 税务法律边界意识：知道业务设计不能乱开票、虚开发票、阴阳合同、虚假交易、乱避税。
- 284. 数据与隐私法律意识：是否懂客户数据、员工数据、交易数据、用户信息不能乱收、乱用、乱传。
- 285. 刑事风险边界意识：能不能识别诈骗、挪用、侵占、虚开发票、非法吸收资金、侵犯商业秘密等高危行为。
- 286. 行政处罚风险意识：是否知道很多“小违规”会变成罚款、停业、吊证、信用记录受损。
- 287. 法律文书理解能力：能不能读懂律师函、起诉状、判决书、调解协议、行政处罚决定书等关键文件。
- 288. 外部律师管理能力：会不会选择律师、管理律师、判断律师水平，而不是完全被律师带着走。
- 289. 法律成本意识：知道打官司、维权、合规整改都有成本，不能为了情绪打仗。
- 290. 法律与商业平衡能力：不是见风险就不做，而是能判断哪些风险可控、哪些绝对不能碰。
- 291. 法务复盘能力：纠纷结束后，能不能把教训变成合同模板、流程规则、审批制度和证据标准。

<a id="class-x"></a>

### X类：专利、知识产权与技术壁垒专项能力

- 292. 知识产权整体意识：是否知道专利、商标、版权、商业秘密、软件著作权、域名、设计稿、数据库都可能是资产。
- 293. 专利价值判断能力：能不能判断一个专利是真有保护价值，还是只是用来凑数量。
- 294. 专利挖掘能力：能不能从研发、产品、工艺、算法、结构、流程中发现可申请的创新点。
- 295. 专利布局能力：不是单点申请，而是围绕核心技术、产品路线、竞争壁垒做组合布局。
- 296. 专利检索能力：能不能通过专利检索了解已有技术、竞争对手布局、侵权风险和空白机会。
- 297. FTO自由实施判断能力：产品上市前，能不能判断是否可能侵犯他人专利。
- 298. 权利要求理解能力：能不能看懂专利真正保护的范围，不被标题和摘要误导。
- 299. 专利申请质量意识：知道专利不是交上去就行，写得差等于没有保护力。
- 300. 专利组合管理能力：能不能管理哪些专利保留、哪些放弃、哪些加强、哪些用于防御或谈判。
- 301. 商业秘密保护能力：知道有些东西不适合公开申请专利，而要通过保密制度、权限、合同来保护。
- 302. 商标布局能力：品牌名、产品名、logo、品类、国家地区是否提前注册和防御。
- 303. 版权保护意识：内容、图片、视频、软件代码、课程、设计、文案、方案是否有版权边界。
- 304. 知识产权侵权识别能力：能不能发现别人抄袭、仿冒、盗用、山寨、非法使用公司资产。
- 305. 知识产权维权能力：发现侵权后，能不能取证、投诉、谈判、发函、诉讼或行政处理。
- 306. 知识产权风险规避能力：产品、广告、包装、代码、设计、名称上线前，能不能避免踩别人权利。
- 307. 竞争对手知识产权监控能力：能不能长期跟踪竞争对手专利、商标、产品、技术路线变化。
- 308. 知识产权商业化能力：能不能把专利、商标、版权变成授权、合作、融资、估值、市场壁垒。
- 309. 海外知识产权意识：跨境业务时，是否知道商标、专利、版权在不同国家需要分别布局。
- 310. 知识产权与研发协同能力：研发、产品、法务、市场之间能不能形成知识产权保护闭环。
- 311. 技术壁垒构建能力：能不能通过专利、工艺、数据、供应链、算法、品牌、标准共同形成壁垒。

<a id="class-y"></a>

### Y类：品牌、品牌资产与声誉管理专项能力

- 312. 品牌定位能力：能不能说清楚品牌是谁、服务谁、解决什么问题、凭什么被选择。
- 313. 品牌差异化能力：能不能建立与竞争对手不同的清晰位置，而不是大家说一样的话。
- 314. 品牌核心价值提炼能力：能不能提炼品牌最重要的价值主张、信任理由和长期承诺。
- 315. 用户心智理解能力：是否知道客户脑子里如何分类、如何比较、如何记住一个品牌。
- 316. 品牌故事能力：能不能讲出让客户、员工、合作方理解并记住的品牌故事。
- 317. 品牌信任构建能力：能不能通过产品、服务、案例、背书、口碑、专业度让客户相信。
- 318. 品牌一致性管理能力：名称、视觉、话术、服务、价格、渠道、员工表现是否一致。
- 319. 品牌视觉判断能力：能不能判断logo、包装、门店、海报、官网、视频、物料是否符合品牌气质。
- 320. 品牌语言体系能力：能不能建立统一的品牌口号、介绍、产品话术、销售话术、对外表达。
- 321. 品牌资产沉淀能力：能不能把客户案例、用户评价、媒体报道、荣誉、专利、数据、故事沉淀下来。
- 322. 品牌溢价能力：品牌能不能让客户愿意付更高价格，而不是只能靠低价成交。
- 323. 品牌长期主义能力：是否知道品牌不是一次活动，而是长期一致行为的结果。
- 324. 品牌体验管理能力：客户从第一次看到、咨询、购买、使用、售后到复购，体验是否统一。
- 325. 口碑管理能力：能不能持续收集、放大、维护客户口碑，而不是只靠广告。
- 326. 品牌危机敏感度：品牌受到投诉、负面评价、舆论攻击时，能不能及时识别风险等级。
- 327. 创始人 / 高管个人品牌管理能力：创始人、高管言行是否能增强公司信任，而不是制造风险。
- 328. 雇主品牌能力：公司对人才有没有吸引力，外部人才是否愿意加入，内部员工是否愿意推荐。
- 329. 品类占位能力：能不能让品牌在某个品类、场景、关键词上形成清晰占位。
- 330. 品牌数据评估能力：能不能用认知度、转化率、复购率、推荐率、客单价、口碑反馈评估品牌效果。
- 331. 品牌护城河意识：是否知道品牌最终不是好看，而是降低获客成本、提高信任、提高溢价、增强复购。

<a id="class-z"></a>

### Z类：公关、攻关与复杂关系突破能力

攻关不是灰色摆平，而是在合法合规范围内突破复杂局面。

- 332. 关键利益方识别能力：能不能识别一件事真正相关的人：决策者、影响者、反对者、受益者、风险方。
- 333. 关键人定位能力：知道谁是能推动事情的人，谁只是表面热闹的人。
- 334. 关系进入能力：能不能用合适方式进入一个陌生圈层、组织、客户、政府机构、行业协会。
- 335. 信任建立能力：能不能让对方从防备、观望，逐步转向愿意沟通、愿意合作。
- 336. 议题设置能力：能不能把事情用对方能接受的方式表达出来，让对方愿意听。
- 337. 利益对齐能力：能不能找到双方共同利益，而不是单方面要求别人帮忙。
- 338. 面子与台阶设计能力：复杂关系里，能不能给对方留面子、留退路、留台阶。
- 339. 高压沟通能力：面对投诉、冲突、监管、客户发怒、合作方翻脸时，能不能稳住。
- 340. 冲突降温能力：能不能让矛盾从情绪对抗回到事实、规则和解决方案。
- 341. 资源协调能力：能不能同时调动法律、品牌、公关、业务、财务、外部顾问、关键关系一起解决问题。
- 342. 攻坚路径设计能力：面对难题，不是蛮干，而是设计先找谁、后找谁、先解决什么、最后落什么结果。
- 343. 关键时机判断能力：知道什么时候该推进、什么时候该停、什么时候该沉默、什么时候该表态。
- 344. 第三方背书使用能力：能不能合法合理地使用专家、媒体、协会、客户、顾问、合作方作为信任背书。
- 345. 舆论沟通能力：面对外部关注时，能不能说清楚事实、态度、措施和边界。
- 346. 媒体沟通能力：能不能理解媒体需求，同时守住公司表达边界，不乱说、不乱承诺。
- 347. 危机公关攻关能力：负面事件发生后，能不能快速判断、统一口径、安抚相关方、修复信任。
- 348. 政商沟通边界能力：与政府、监管、行业组织沟通时，能不能合法、专业、不越线。
- 349. 复杂项目破局能力：项目卡住时，能不能找到真正卡点并推动关键人、关键资源、关键条件松动。
- 350. 后续关系维护能力：攻关不是办完一次事就结束，能不能持续维护信任，避免用完即丢。
- 351. 攻关合规意识：任何关系突破都不能变成行贿、威胁、造假、违规承诺或灰色交易。

<a id="class-aa"></a>

### AA类：策划、方案、战役设计与落地能力

- 352. 策略策划能力：能不能先判断目标、对象、资源、限制，再设计方案，而不是直接想创意。
- 353. 目标定义能力：能不能把“做个活动”“搞个推广”变成清晰目标：拉新、转化、成交、复购、曝光、信任、招商。
- 354. 用户画像能力：能不能准确描述目标人群是谁、痛点是什么、顾虑是什么、为什么会行动。
- 355. 场景洞察能力：知道用户在什么场景下会看到、相信、咨询、购买、传播。
- 356. 传播主题提炼能力：能不能提炼一句清楚、有吸引力、能传播的核心主题。
- 357. 创意能力：能不能提出新鲜、有记忆点、有传播力，同时不脱离业务的创意。
- 358. 方案结构能力：一份方案是否有背景、目标、洞察、策略、动作、预算、风险、效果评估。
- 359. 活动策划能力：能不能设计线下活动、发布会、招商会、沙龙、展会、客户答谢会等完整流程。
- 360. 内容策划能力：能不能设计文章、短视频、直播、海报、案例、白皮书、话术、课程等内容体系。
- 361. 产品上市策划能力：新品推出时，能不能设计节奏、卖点、渠道、培训、物料、传播、销售配合。
- 362. 销售战役策划能力：能不能围绕季度目标、重点客户、重点区域设计一场有节奏的销售战役。
- 363. 渠道策划能力：能不能针对代理商、经销商、合作伙伴设计招商、激励、培训和支持方案。
- 364. 节奏设计能力：策划不是一锤子买卖，要知道预热、爆发、承接、转化、复盘怎么安排。
- 365. 预算配置能力：知道钱该花在哪里，不该花在哪里，哪些动作值得投入，哪些只是热闹。
- 366. 转化路径设计能力：看见、感兴趣、咨询、成交、复购、推荐，每一步有没有承接动作。
- 367. 执行拆解能力：方案能不能拆成负责人、时间表、物料表、预算表、检查点。
- 368. 风险预案能力：策划前是否想过现场冷场、客户不来、舆论误解、预算超支、供应商掉链子。
- 369. 效果评估能力：活动或方案结束后，能不能用数据和结果判断成败，不只看感觉。
- 370. 复盘优化能力：能不能把一次策划经验变成下一次更好的方法。
- 371. 策划落地能力：不是方案写得漂亮，而是最终真的产生客户、信任、销售、品牌、组织效果。

<a id="class-ab"></a>

### AB类：人性理解与行为应用能力

懂人性不是操控人，而是识人、育人、激励人、防风险。

- 372. 欲望识别能力：能不能看出一个人真正想要的是钱、权、名、安全感、自由、成长、认可，还是控制感。
- 373. 恐惧识别能力：能不能看出员工、客户、合作方、管理者害怕什么：失败、失控、丢脸、失去利益、被替代。
- 374. 利益驱动理解能力：知道人不是只听道理，很多行为背后是利益结构在推动。
- 375. 面子心理理解能力：能不能理解面子、尊严、台阶在沟通和管理中的作用。
- 376. 安全感机制理解能力：知道员工为什么防御、客户为什么犹豫、合作方为什么反复。
- 377. 嫉妒心理识别能力：能不能识别团队里因为优秀者冒头而产生的打压、阴阳怪气、排挤。
- 378. 虚荣心理识别能力：能不能看出一个人是否过度追求头衔、排场、表扬、存在感。
- 379. 贪婪识别能力：能不能看出一个人对钱、权、资源、地位是否没有边界。
- 380. 怨气识别能力：能不能发现员工、管理者、合作方长期积累的不满和潜在爆点。
- 381. 忠诚本质判断能力：能不能区分真忠诚、利益绑定、情绪依赖、讨好表演、暂时站队。
- 382. 激励机制设计能力：能不能根据人性设计奖金、晋升、荣誉、成长、授权、反馈机制。
- 383. 约束机制设计能力：知道光靠信任不够，还要有规则、监督、证据、审批、边界。
- 384. 信任建立能力：能不能通过稳定、兑现、公平、透明建立长期信任。
- 385. 信任破裂修复能力：出现误解、冲突、失误后，能不能修复关系，而不是让裂缝扩大。
- 386. 群体心理理解能力：能不能理解团队情绪、从众、站队、流言、恐慌、集体沉默。
- 387. 组织风气塑造能力：能不能利用规则、奖惩、榜样、语言、仪式和标准塑造团队风气。
- 388. 说服路径设计能力：知道不同人要用不同说服方式：事实、利益、风险、情感、权威、案例。
- 389. 行为设计能力：能不能通过流程、默认选项、提醒、反馈、奖惩，让正确行为更容易发生。
- 390. 人性黑暗面防范能力：知道人会贪、会懒、会怕、会装、会甩锅、会谋私，所以提前设计制度防坏。
- 391. 人性应用边界：懂人性但不用来操控、欺骗、PUA、精神压迫，而是用于成事、育人、控风险。

<a id="class-ac"></a>

### AC类：人力资源、找人、用人、留人专项能力

- 392. 岗位画像能力：能不能清楚定义这个岗位到底要解决什么问题，而不是简单写岗位职责。
- 393. 人才标准制定能力：能不能说清楚这个岗位什么人合适，什么人不合适，哪些能力必须有。
- 394. 招聘渠道建设能力：能不能建立内推、猎头、行业圈、校园、社群、合作方等多元渠道。
- 395. 人才地图能力：是否知道行业里好人才在哪里、在哪些公司、什么层级、什么价格。
- 396. 简历识别能力：能不能从简历里看出真实经历、包装成分、岗位匹配度和风险点。
- 397. 面试提问能力：能不能通过行为问题、案例追问、压力追问看出真实能力。
- 398. 面试识假能力：能不能识别假履历、假项目、假资源、假管理经验、假业绩。
- 399. 背调能力：会不会问上级、平级、下属、客户、供应商，而不是只听候选人讲故事。
- 400. 薪酬谈判能力：能不能在控制成本的情况下吸引人才，同时不破坏内部公平。
- 401. 入职适配能力：新人进来后，能不能快速明确目标、资源、规则、关系、考核。
- 402. 试用期评估能力：30、60、90天分别看什么，能不能及时发现不匹配。
- 403. 人岗匹配能力：能不能把合适的人放到合适的位置，而不是凭喜欢或关系用人。
- 404. 高潜人才识别能力：能不能识别现在还不成熟，但未来可能成长为骨干或干部的人。
- 405. 干部选拔能力：能不能从业务能力、心性、责任、带人、抗压、组织安全等角度选干部。
- 406. 梯队建设能力：关键岗位有没有后备人才，不让组织被一个人绑架。
- 407. 培训体系建设能力：能不能把新人培训、岗位培训、干部培训、专业培训做成体系。
- 408. 绩效管理能力：能不能设目标、看过程、评结果、做反馈、连奖惩。
- 409. 激励体系设计能力：奖金、晋升、荣誉、授权、成长机会是否能激发正确行为。
- 410. 淘汰机制设计能力：能不能处理长期低效、价值观不合、破坏团队的人。
- 411. 员工关系处理能力：员工冲突、投诉、离职、劳动争议、情绪问题能不能稳妥处理。
- 412. 用工合规能力：招聘、合同、社保、薪资、加班、调岗、辞退是否守住法律边界。
- 413. 组织诊断能力：能不能判断问题是人不行、机制不行、目标不清、激励错了，还是领导有问题。
- 414. 文化落地能力：不是贴标语，而是把价值观落实到招聘、晋升、奖惩、会议、复盘里。
- 415. 关键人才保留能力：能不能留住核心人才，不只是加钱，还包括成长、尊重、机会、机制。
- 416. 人才盘点能力：能不能定期盘点谁能上、谁要换、谁可培养、谁有风险。
- 417. 组织结构设计能力：能不能根据业务阶段设计部门、岗位、汇报线、权责边界。
- 418. 继任计划能力：关键岗位突然离开时，有没有人能接住。
- 419. 外部顾问 / 猎头管理能力：能不能用好猎头、培训机构、咨询顾问，而不是被他们牵着走。
- 420. 管理者赋能能力：HR不是只管手续，而是能帮助管理者招人、用人、带人、淘汰人。
- 421. 人力资源商业理解能力：懂业务、懂利润、懂组织效率，知道人力资源最终是为了业务结果和组织能力。

## 第二部分：115项高危反向指标

这些不是普通缺点。分数越高，风险越大。严重者一票否决。

- R1. 不可信任风险

不能放心交钱、交人、交资源、交信息。

- R2. 甩锅风险

出了问题习惯推给下属、老板、客户、环境、其他部门。

- R3. 内耗风险

制造会议、争吵、流程消耗、人际矛盾和组织摩擦。

- R4. 山头主义风险

把公司团队变成自己的私人势力。

- R5. 表演型管理风险

会汇报、会喊口号、会包装，但实际结果差。

- R6. 情绪化管理风险

凭心情安排工作、评价员工、处理问题。

- R7. 打压下属风险

害怕下属成长，喜欢压制能人。

- R8. 报喜不报忧风险

隐瞒问题，等事情爆雷才暴露。

- R9. 权力膨胀风险

一有职位就摆架子、乱用权、压人、变脸。

- R10. 关系滥用风险

把人脉、社会关系、金融资源、监管资源变成谋私或压人的工具。

- R11. 跨国资源失控风险

海外资源掌握在个人手里，公司无法核实、无法监督、无法替代。

- R12. 数据造假风险

为了业绩、奖金、面子、升职而美化或篡改数据。

- R13. 虚假承诺风险

对老板、客户、员工、合作方乱承诺，最后公司买单。

- R14. 回扣风险

在采购、工程、渠道、供应商合作中收取私利。

- R15. 利益输送风险

把公司资源、订单、客户、项目输送给自己人。

- R16. 私设小金库风险

在团队、项目、外部合作中形成不透明资金池。

- R17. 资源私有化风险

客户、渠道、供应商、政府关系、海外资源只认他，不认公司。

- R18. 故意制造不可替代风险

不培养下属、不沉淀流程、不透明信息，让公司离不开他。

- R19. 欺上瞒下风险

对上包装，对下歪曲老板意思。

- R20. 泄密风险

泄露价格、客户、合同、战略、财务、人事、技术资料。

- R21. 客户勾连风险

和客户私下达成利益交换，损害公司利益。

- R22. 供应商勾连风险

和供应商形成私下利益链。

- R23. 职场霸凌风险

利用职位长期羞辱、恐吓、打压员工。

- R24. 性骚扰与不当关系风险

利用职权发展不当关系，或造成法律、声誉、团队风险。

- R25. 灰色关系依赖风险

总想靠“摆平”“打招呼”“特殊通道”解决问题。

- R26. 被外部控制风险

因为债务、赌博、隐秘利益、把柄、灰色关系，被外部人员控制或利用。

- R27. 形象败坏风险

个人言行长期损害公司形象、团队信任和外部评价。

- R28. 双标管理风险

要求别人一套，自己一套。

- R29. 低俗化风险

语言、玩笑、酒局、应酬、男女关系、办公室行为低俗，污染团队风气。

- R30. 私德外溢风险

私人生活问题已经影响公司声誉、团队公平、岗位稳定或商业安全。

- R31. 合规红线无感风险

为了短期结果，什么规则都敢碰。

- R32. 组织破坏风险

他在团队里不是增加秩序，而是制造恐惧、抱怨、混乱和对立。

- R33. 心术不正风险

表面忠诚、勤奋、能干，实际内心算计重、阴招多、目的不纯。

- R34. 无良心风险

为了利益可以坑公司、坑客户、坑员工、坑合作方，事后没有愧疚感。

- R35. 见利忘义风险

有利益就忘承诺、忘恩情、忘规则、忘底线。

- R36. 恩将仇报风险

公司培养他、老板信任他、同事帮过他，最后反过来拆台、背刺、抢资源。

- R37. 欺软怕硬风险

对上讨好，对下欺压；对强者低头，对弱者凶狠。

- R38. 冷血利用人风险

只把人当工具，用完就丢，不顾别人基本处境和尊严。

- R39. 伪善包装风险

嘴上讲道德、讲感恩、讲团队，实际做事自私、阴险、狠毒。

- R40. 报复心过重风险

别人提意见、挡了他的利益、没有顺从他，他就找机会报复。

- R41. 贪婪失控风险

钱、权、色、资源、名声、地位都想要，欲望没有边界。

- R42. 无羞耻心风险

撒谎、甩锅、占便宜、伤害别人、违背承诺后，毫无难堪和反省。

- R43. 容不得人风险

容不得能人、强人、直言的人、有独立判断的人。

- R44. 道德绑架风险

表面讲感恩、忠诚、义气，实际用这些词控制别人、压制不同意见。

- R45. 两面三刀风险

当面热情支持，背后挑拨、拆台、告状、设局。

- R46. 说一套做一套风险

嘴上讲规则，自己破坏规则；嘴上讲责任，出事先甩锅。

- R47. 表演型人格风险

长期靠演来获得信任、资源和位置。

- R48. 伪忠诚风险

嘴上忠诚，实际只忠于利益。

- R49. 伪感恩风险

嘴上感谢公司，实际只索取、不回馈。

- R50. 伪正直风险

表面讲原则，实际用原则打击异己、包装私心。

- R51. 装委屈风险

遇到责任就把自己包装成受害者。

- R52. 装努力风险

表现得很忙、很累、很辛苦，但没有真实产出。

- R53. 装专业风险

术语很多、概念很多、PPT很漂亮，但底层逻辑空。

- R54. 装资源风险

把“认识”包装成“能调动”，把“听说”包装成“有渠道”。

- R55. 装格局风险

嘴上讲大局、战略、长期主义，实际不愿承担具体责任。

- R56. 装受害者操控风险

通过示弱、诉苦、卖惨、制造亏欠感来操控别人。

- R57. 高级包装风险

系统性包装履历、资源、贡献、忠诚、人设、能力、影响力。

- R58. 隐性操控风险

通过话术、情绪、信息差、关系网操控局面。

- R59. 恶意揣摩与误判风险

把正常失误理解成背叛，把不同意见理解成挑战权威。

- R60. 直觉自负风险

自以为商业直觉很准，不验证、不听劝、不复盘。

- R61. 伪创新风险

换个名字叫创新，换个包装叫模式，实际没有真实价值。

- R62. 概念空转风险

概念越来越多，行动越来越少，结果没有改善。

- R63. 为颠覆而颠覆风险

为了显示自己高级，就否定过去。

- R64. 破坏大于建设风险

旧东西打碎了，新东西没建起来。

- R65. 规则任性化风险

把创建规则变成“我说了算”。

- R66. 创新不算账风险

只讲未来，不算成本、人力、现金流、失败代价。

- R67. 豪赌式创新风险

没有小试点、没有验证、没有风控，直接大投入。

- R68. 迷信新东西风险

认为新的就比旧的好，外来的就比原来的好。

- R69. 过度复杂化风险

把简单问题复杂化，把清楚流程搞成复杂系统。

- R70. 个人英雄式创新风险

所有创新都依赖他个人，别人学不会、接不住、复制不了。

- R71. 脱离现实风险

想法宏大，但不理解团队能力、客户需求、现金流和执行难度。

改革、创新、重构时节奏失控，导致业务断档、团队恐慌。

新规则设计不严密，反而制造新的灰色空间。

- R74. 创造者傲慢风险

因为自己创造过东西，就听不进意见。

- R75. 颠覆性破坏公司根基风险

为了创新，破坏客户信任、现金流、核心团队、品牌、合规和基本秩序。

明知道有法律风险，但总觉得不会出事。

## 第三部分：简要使用方法

### 1. 不要全量评分

421项是指标池，不是每个岗位都要评。基层管理者选35—45项，中层选50—70项，高层选70—90项，顶级管理者选90—120项。岗位越高，越要看心性、经营、风险、洞察、创造和组织能力。

### 2. 每个岗位用四组指标

第一组是通用底线指标：心性、诚信、守信、良心、合规、保密。第二组是通用管理指标：理解、执行、沟通、带人、闭环、情绪稳定、责任担当。第三组是岗位专项指标：销售看客户和回款，技术看技术判断和研发质量，行政看服务和秩序，财务看资金安全。第四组是高危反向指标：这个岗位最容易出什么风险，就重点查什么风险。

### 3. 评分建议

建议使用5级评分：5分为顶级，4分为优秀，3分为合格，2分为偏弱，1分为危险或严重不足。评分必须配证据等级：A级为可验证结果、数据、合同、制度、流程、财务结果；B级为上级、平级、下属、客户、供应商多方一致反馈；C级为本人叙述且细节可部分验证；D级为感觉和单方印象。D级证据不能作为关键决策依据。

### 4. 一票否决

严重不诚信、数据造假、回扣或利益输送、严重泄密、性骚扰或利用职权发展不当关系、职场霸凌、恩将仇报、严重资源私有化、违法违规摆平、重大合规红线无感、被外部控制、故意制造不可替代、私设小金库、严重山头主义、严重两面三刀，均应一票否决。

### 5. 最终判断

管理人员的核心评价，不是他多聪明、多能干、多有资源，而是他拿到人、钱、权、资源以后，是让公司变强，还是让公司变危险。
